# Project status

RxDjango is being rebuilt from the v0.0.x prototype that lives at
[rxdjango/rxdjango-0](https://github.com/rxdjango/rxdjango). The
current focus is the semantics — serializers, channels, and the
Python↔TypeScript boundary — rather than transport plumbing.

Track ongoing work via the ADRs under `docs/adr/` and the issues on
the GitHub repository.
